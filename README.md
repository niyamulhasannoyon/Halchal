# Halchal (হালচাল)

> **এলাকার কারেন্ট, গ্যাস ও পানির লাইভ খবর**

Hyperlocal, crowd-sourced live utility status platform (electricity, gas, water, LPG) for Bangladesh, designed for cheap Android smartphones, 2G/3G networks, and active blackout conditions.
